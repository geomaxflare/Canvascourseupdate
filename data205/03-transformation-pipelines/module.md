# Module 3: Transformation and Pipelines

## Introduction

Raw data almost never arrives ready for analysis. A **pipeline** moves data from source systems into the analytics platform and transforms it along the way. In this module, we compare the two main pipeline patterns, see why SQL has become the main language of transformation, and learn how teams manage transformations like software: versioned, tested, documented, and scheduled.

## Objectives

- Compare ETL and ELT and explain why ELT has become common on cloud platforms.
- Use SQL to express common transformations such as cleaning, joining, and aggregating.
- Explain how version control, automated tests, and documentation make transformations reliable.
- Describe the role of orchestration and scheduling in running a pipeline.
