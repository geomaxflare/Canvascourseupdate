# Module 7: Preparing Data for AI and Machine Learning

## Introduction

Machine learning models and AI systems learn from data, so the quality of the data sets a ceiling on how good they can be. Preparing data for AI uses everything from this course, including pipelines, quality tests, and governance, plus some new concerns: preventing leakage, processing unstructured text and images, storing embeddings for search, and documenting exactly what a model was trained on.

## Objectives

- Explain good training data hygiene and identify common forms of data leakage.
- Describe the stages of a pipeline that turns unstructured documents into usable data.
- Explain what embeddings are and how vector storage supports similarity search.
- Describe how to document the provenance of a training dataset.
