# Module 6: Data Quality and Governance

## Introduction

A pipeline that runs on time but delivers wrong data is worse than no pipeline at all, because people trust it. In this module, we turn data quality and governance from ideas into practices built into the platform: measurable quality dimensions, automated tests that run with every load, lineage that traces every number to its source, catalogs that help people find and understand data, and contracts that keep producers and consumers in agreement.

## Objectives

- Describe the main dimensions of data quality and give a measurable check for each.
- Write automated data tests and explain where they belong in a pipeline.
- Explain how lineage and data catalogs help people find, understand, and trust data.
- Describe what a data contract contains and why it prevents broken pipelines.
